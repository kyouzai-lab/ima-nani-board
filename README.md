# 今なにする？ボード

授業の流れ（例：考える5分→ペア3分→発表10分）を電子黒板やプロジェクターに映して、「今なにをする時間か」「あとどれくらいか」を子どもが自分で見てわかるようにする先生用の道具。全教科で使える。

- 入口：`index.html` 1枚（ビルドなし・ライブラリなし。文字だけ Google Fonts を読む）
- 端末：iPad（Safari）、Windows（Edge / Chrome）。縦・横どちらでも崩れない
- 保存：localStorage のキー `ima-nani-board:v1` だけ（活動名・分数・授業の長さ）。子どもの名前などは入れる場所がなく、ほかへは送らない

## 画面

1. **準備**：活動を1〜6つ（名前と1〜60分）。順番の入れかえ・けす。授業の長さ（初めは45分）。合計が長いと「予定が○分オーバー」
2. **授業中**：上に流れの札（今の活動が光る・終わった活動はうすく）、まん中に今の活動名と残り時間。下のボタンは −1分・＋1分・＋3分／前へ・一時停止・次へ／おわる・全画面
   - 0になっても自動では進まず、赤い「+1:23」で超過を数える
   - 予定が授業の終わりを過ぎそうになると、右上に「このままだと○分オーバー」
   - 前へ：前の活動を、離れたときの続きから動かす
   - パソコンのキー：スペース＝一時停止／再開、→＝次へ、←＝前へ
3. **おしまい**：活動ごとの予定とじっさいの時間

## 映しっぱなしの工夫

- 授業中は Screen Wake Lock で画面が暗くならないようにする（使えない端末では準備画面に案内を出す）
- 時間は Date.now との差で計算するので、タブが裏に回ってもずれない
- 授業中に再読み込みすると最初からになる（続きからの再開はない）
